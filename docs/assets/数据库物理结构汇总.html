数据库物理结构设计

数据库名称：flight_demo。说明：PK 表示主键，FK 表示外键，UK 表示唯一约束，Not null 表示字段不能为空。系统数据库各表字段含义如下。

表 4.1 系统数据库物理结构汇总表
表名表说明主要字段及含义主键/约束
flight航班信息表，保存航班基础数据。id：航班记录编号；flight_no：航班号；airline_name：航空公司；from_city/to_city：出发/到达城市；from_airport/to_airport：出发/到达机场；depart_time/arrive_time：起飞/到达时间；price：价格；seats_left：余票；data_source：数据来源；collected_at：采集时间。PK：id；UK：flight_no + depart_time + data_source；索引：航线日期、价格。
app_user用户表，保存普通用户账号信息。id：用户编号；username：用户名；password：密码；nickname：昵称；created_at：创建时间。PK：id；UK：username。
user_token登录令牌表，保存用户登录状态。id：令牌编号；user_id：用户编号；token：登录令牌；created_at：创建时间；expires_at：过期时间。PK：id；UK：token；索引：token、user_id。
favorite收藏表，保存用户收藏航班记录。id：收藏编号；user_id：用户编号；flight_id：航班编号；created_at：收藏时间。PK：id；FK：user_id、flight_id；UK：user_id + flight_id。
crawl_job采集任务表，记录爬虫任务执行情况。id：任务编号；status：任务状态；started_at：开始时间；finished_at：结束时间；success_count：成功数量；failed_count：失败数量；error_message：错误信息；source：数据源；request_params：请求参数。PK：id；索引：started_at。
flight_price_snapshot价格快照表，保存航班价格历史。id：快照编号；flight_id：航班编号；flight_no：航班号；from_city/to_city：航线城市；depart_time：起飞时间；price：快照价格；seats_left：快照余票；data_source：数据来源；observed_at：观测时间。PK：id；索引：flight_id + observed_at、航线日期。
flight_validation_failure校验失败记录表，保存采集时被拒绝的数据。id：失败记录编号；crawl_job_id：采集任务编号；flight_no：航班号；from_city/to_city：航线城市；depart_time：起飞时间；price：价格；seats_left：余票；failure_reason：失败原因；rejected_at：拒绝时间。PK：id；索引：crawl_job_id + rejected_at。
price_context价格上下文表，保存价格趋势文本。id：上下文编号；from_city/to_city：航线城市；depart_date：出发日期；context_text：上下文文本；context_type：上下文类型；created_at：创建时间。PK：id；索引：航线；全文索引：context_text。
conversation_session会话表，保留 AI 会话基础信息。id：会话编号；title：会话标题；created_at：创建时间；updated_at：更新时间。PK：id。
conversation_message会话消息表，保留会话内容。id：消息编号；session_id：会话编号；role：消息角色；content：消息内容；created_at：创建时间。PK：id；索引：session_id + created_at。
