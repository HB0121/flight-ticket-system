用户注册详细说明如表 3.1 所示：

表 3.1 用户注册详细设计说明

功能名称 用户注册
涉及数据表 app_user 用户表
功能表述 普通用户填写用户名和密码，系统完成账号创建。注册成功后，用户可以使用该账号登录系统并使用航班查询、收藏和搜索历史等功能。
输入项 用户名、密码
业务处理描述 用户提交注册信息后，系统首先校验用户名和密码是否为空，再校验用户名是否已经存在。若信息合法，则将用户信息写入 app_user 表；若用户名重复或信息不完整，则返回错误提示，要求用户重新填写。
输出项（正确） 注册成功，返回用户基础信息 输出项（错误） 提示用户名已存在或填写内容不完整
界面要求 Web 页面，需提供用户名和密码输入框、注册按钮以及错误提示信息。

用户登录详细说明如表 3.2 所示：

表 3.2 用户登录详细设计说明

功能名称 用户登录
涉及数据表 app_user 用户表、user_token 登录令牌表
功能表述 普通用户输入用户名和密码进行登录。登录成功后，系统生成 token，并通过该 token 识别用户身份，使用户可以访问个人收藏、搜索历史等功能。
输入项 用户名、密码
业务处理描述 系统根据用户名查询 app_user 表，并校验密码是否正确。若校验成功，则生成登录 token，写入 user_token 表并返回给前端；若校验失败，则返回登录失败提示，不生成 token。
输出项（正确） 登录成功，返回 token 和用户信息 输出项（错误） 提示用户名或密码错误
界面要求 Web 页面，需提供用户名、密码输入框和登录按钮；登录成功后跳转至航班查询页面。

航班查询与收藏详细说明如表 3.3 所示：

表 3.3 航班查询与收藏详细设计说明

功能名称 航班查询与收藏
涉及数据表 flight 航班表、flight_price_snapshot 价格快照表、favorite 收藏表
功能表述 用户根据出发地、目的地和日期查询航班信息，查看航班详情及价格历史，并可将感兴趣的航班加入个人收藏列表。
输入项 出发地、目的地、出发日期、航班编号、收藏操作指令
业务处理描述 系统接收查询条件后，从 flight 表中筛选航班数据并返回列表。用户查看详情时，系统读取航班基础信息和价格快照数据。用户点击收藏时，系统先判断 favorite 表中是否已有记录，未收藏则写入收藏记录，已收藏则返回提示。
输出项（正确） 返回航班列表、详情、价格历史或收藏成功信息 输出项（错误） 提示暂无数据、航班不存在或已收藏
界面要求 Web 页面，需提供查询条件输入区、航班列表、详情展示区、价格历史图表和收藏操作按钮。
